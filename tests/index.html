Tests

An assertion, not a score.

Every class on this site ends in the same shape. State before. Action. State after. A scanner percent and a model sentence do not satisfy it.

Contract tests you can run

  • Vault — forge test. One deposit must hit both ledgers. The broken variant fails. The patched invariants hold.
  • Pool — forge test. First-depositor inflation and a fee on the balance. Thirty-two tests on the fixed contracts.
  • zk gate — forge test. A tampered journal, a wrong image id, and a bad selector are rejected.

Web assertions

Two users. B asks for A’s object. Denial, and A’s row unchanged. A fresh install. The debug route is absent. A webhook with the signature removed does not write. The full table is examples/assertions.md.

Agent assertions

Same user prompt, two fixtures. The write count stays equal. A search as tenant A, with the product’s own filter on, does not return B. A private MCP resource with no caller credential is a denial. If the tool-call JSON does not parse, the environment check did not run. That is not a failed utility. It was not measured.

What a pack contains

The property table. The test or the request log. The walkthrough. Fourteen days to re-run the same tests after your patch. No second invoice inside that window.
