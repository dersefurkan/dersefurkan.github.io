Why this work exists

Contests and audit PDFs are a snapshot. Production breaks on the path that was added last Tuesday. The expensive class is almost always the same: the protocol tracks the wrong identity for money — or takes a fee on principal instead of gain, while the ledger still “balances.”

01

The extra exit

Deposit credits shares and a receipt. Each withdraw burns only one. Same pile, two claims. Queue cursors, fast/slow paths, and trusted-forwarder flows are the same shape.

02

The next commit

Sherlock/Cantina wrap, report lands, then a patch ships. If CI does not fail when a double-claim reopens, the report was a souvenir. The suite is the product that stays.

03

The zkVM seam

Guest proves X. Journal commits Y. Verifier checks Z. If image ID is unpinned or the journal is not bound to chain context, a valid proof is still the wrong story. Auditor supply on this layer is thin — that is the niche.
