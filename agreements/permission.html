Permission to test

The client authorizes Furkan Derse to test only the staging system named below, for the days of the review.

  • Host or repository: [staging URL or commit].
  • Account or role: [one role the client creates].
  • Flows: [the list]. Anything not listed is out.

Allowed

Read the named flows. Send the requests those flows already support. Record status codes, tool logs, and the state after the request. Use test data the client provides.

Not allowed

Production, unless a separate line names it. Deleting or paying real user data. Scanning hosts that are not in the list. Testing a third party’s public API. Sharing credentials outside the private repo.

Stop

Either party can stop the test by email. Work already in the private repo stays there. The client confirms they control the staging system and may grant this permission.
