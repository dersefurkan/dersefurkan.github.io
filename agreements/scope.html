Review scope

Between the client and Furkan Derse. One surface, named here: [contract family / staging web app / zk guest and verifier / agent endpoint].

Term

Five business days, starting when the fee has landed and this page’s blanks are filled. Fee: 750 USD, USDC or bank transfer. Invoice on request.

Work

A report for the named surface. Each finding, the evidence, and the fix. Contracts and zk: the evidence includes a test that fails before the patch and passes after, kept in a private repository. Web and agents: the evidence is the request or the tool log and the state after. No ongoing detector. One walkthrough. Fourteen days after delivery to re-run the same checks on your patch, no second invoice.

Not included

This is a security review of the named surface. It is not a security audit and not a guarantee. A second system, a diff over 800 lines, production destruction, and a vendor’s public chat are out. A green result means the tested properties held under the tested conditions.

Blanks

  • Surface name and URL or commit.
  • Role under test, if the surface is a web app or an agent.
  • Tools, documents, and tenants, if the surface is an agent.
  • Out of scope, in the client’s words.
  • Where the report is delivered: a named inbox, or the private repo. Sending that file is delivery.
  • Who applies the fix, and who sends the patched commit or staging build for the one re-run.

The file is the report: each finding, the evidence, and the fix in writing. It is not a certificate, a deployed patch, or a detector left running. The walkthrough only reviews that report. A clean result is the same report. Nothing further is owed.
