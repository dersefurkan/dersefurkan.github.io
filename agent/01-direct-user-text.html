Agents

1. Direct user text

Description. The user's sentence is the only order the tool sees. There is no second check of who is allowed to move the money, send the mail, or delete the row. The model is obedient, and the tool is open.

Why it matters. A chat box becomes an admin console. The finding is the tool call and the state, not a rude reply.

Detection hints.

  • List the tools the scoped endpoint can call. Mark which ones change state.
  • Send one in-scope request that names a legal action, and one that names an action the role must

    • not have.

  • Read the tool log. The argument and the caller's identity are both required.
  • Invariant: the forbidden action does not change the ledger, the mailbox, or the row.

Example test. A normal user asks the agent to export another user's records. Assert no export file and no tool call that reads that user. A same-user request that the product allows may succeed. That success is the control case, not the finding.

Public references.

  • OWASP Top 10 for LLM Applications
  • MITRE ATLAS
  • AgentDojo, arXiv:2406.13352

Field note

The user's sentence is the only order the tool sees. Nothing else checks who may move money, send mail, or delete a row. The model obeys and the tool stays open, so a chat box acts as an admin console. The finding is the tool call and the changed state, not a rude reply.

Detection hint. Read the tool log for a forbidden action: both the argument and the caller's identity must be present, and the ledger, mailbox, or row must stay unchanged.

Example. A normal user asks the agent to export another user's records. Assert no export file and no tool call that reads that user. A same-user request the product allows may succeed; that success is the control, not the finding.

Public reference. OWASP Gen AI Top 10 (2025), including LLM06 Excessive Agency: https://genai.owasp.org/llm-top-10/
