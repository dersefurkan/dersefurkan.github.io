6. MCP caller and resource

Description. The server speaks MCP. initialize works. A tool or a resource then ignores the caller. The private resource returns its body with no Authorization and no session subject. A tool description is not a policy. A note that says "do not call this" is not a check.

Why it matters. The model is one client. A second client can call resources/read or tools/call itself. A finding that exists only when a model is persuaded is smaller than a finding that exists on the protocol.

Detection hints.

  • Record the protocol version, whether a session id is set, and whether a credential header was

    • sent.

  • Call resources/read on each private URI with no credential. A body is the finding. The bytes

    • of the secret do not go in the report. The status and the length do.

  • Separately, ask the agent to summarize. If it does not request the private URI, say so. That

    • does not close the direct read.

  • Invariant: a private resource without a caller check is a fail even if every model refused.

Example test. No authorization header. resources/read on the private URI. Assert denial. A 200 is a fail. Do not paste the body.

Field note

initialize can succeed while a tool or resource ignores the caller. A private body with no Authorization and no session subject is exposed. "Do not call this" is not a check.

The model is one client. Another can call resources/read or tools/call. Persuading the model is weaker than a direct protocol read.

Detection. Note protocol version, session id, and any credential. Read each private URI with no credential. Report status and length, not bytes. If the agent skips the URI, say so; that does not close the direct read. No caller check fails even if every model refused.

Added hint. The 2025-06-18 spec says the protocol does not enforce access control, and tool annotations are untrusted. From a second JSON-RPC client, resources/read with no Authorization. A 200 and a non-empty body is a fail.

Test. No authorization header. Expect denial. Do not paste the body.
