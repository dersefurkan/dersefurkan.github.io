Three triage questions

Ask after measured effect, before the report. They set the band. No written scope means no finding. No evidence means no finding. Live and tested builds must match.

1. Default install

Does a normal install open this path, with no test flag? Critical is only that path: no login or a normal user, and a lasting write or broad read of someone else's asset. A flag the test enabled is not Critical. A lab demo is not the product default.

2. Who supplied the prerequisite

Did the product supply it, or the harness, an extra role, or an extra user action? High is the same end state only with that extra legitimate step. A planted secret or added tool does not count.

3. Isolated step or full effect

Measure the end state. A bad sentence is not impact. A refusal with no tool log is not a finding. One helper return is not the job. Full effect is the recorded result on another party's asset, a file, an order, another session, or a cost cap. Two runs, one variable changed. If any answer is no, lower the band or leave a hypothesis.
